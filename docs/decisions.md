## Questions to ask at the relevant implementation gate

1. At slice 1: approve any externally sourced art/audio asset and its license before inclusion; use original procedural assets by default.
2. At slice 2: approve local interactive Builder ID sign-in/read-only live smoke test. Do not send tokens in chat.
3. At slice 3: confirm Bedrock model/region, credential loading and cost expectations before making any model request; approve any real schedule write test separately.
4. For D-21: cloud provider (e.g. DynamoDB in the participant's AWS account), identity (Builder ID `sub` vs anonymous device ID), region, cost ceiling, retention/deletion and privacy notice; whether the hosted preview may write to it.
5. Before submission: review the independent repo setup and public contents, then explicitly request commit/remote/deployment if desired.
